# 短剧投稿平台规格与合规

> 交付包中的 `platforms.json` 与「投稿与合规说明.md」会随项目自动生成，本文档为各平台完整规格参考。

## 通用投稿要求（AI 生成内容）

1. 发布时在平台勾选「AI 生成内容」标识（抖音/快手/红果均支持）。
2. 不得使用真实人物的肖像、声音；不得包含侵权音乐/素材。
3. 剧情不得含暴力血腥、擦边、赌博、封建迷信、危害未成年人等内容。
4. 每集建议独立封面 + 分集简介，标题 ≤ 20 字。

## 抖音（douyin）

- 竖屏 9:16，分辨率建议 1080x1920（平台最低 720x1280）。
- 单集时长 60-180 秒为宜（超过 180 秒会被归入"中视频"赛道，流量逻辑不同）。
- 封面：1080x1440 或 1080x1920，主角居中、情绪强、标题大字。
- 字幕：底部安全区（下 1/3），字号 ≥ 屏高 5%，白字黑边。
- 发布时选「短剧」标签，勾选 AI 标识；可通过「抖音短剧」小程序提交长剧。

## 快手（kuaishou）

- 竖屏 9:16，分辨率 720x1280 起，码率建议 ≥ 3Mbps。
- 单集 60-180 秒；单条视频 ≤ 10 分钟。
- 封面：1080x1920。
- 标题 ≤ 20 字；首屏 3 秒要有钩子（强冲突或悬念）。
- 发布时勾选 AI 生成标识。

## 红果短剧（hongguo）

- 竖屏 9:16，1080x1920；横屏剧单集 3-8 分钟。
- 完整剧集提交需要：分集视频 + 分集简介 + 角色海报 + 总简介。
- 支持按"整剧"提交，审核更关注前 3 集与封面。
- 字幕白字黑边，底部安全区内。

## 本项目的自动适配

- 交付包按 720x1280 生成（Seedance 720p），满足快手最低要求；投稿抖音/红果前建议用平台工具或 ffmpeg 升到 1080x1920：

```powershell
ffmpeg -i final.mp4 -vf "scale=1080:1920:flags=lanczos" -c:v libx264 -preset slow -crf 18 -c:a aac final-1080.mp4
```

- `metadata.json` 已含 `ai_generated: true` 与合规建议；字幕已标注「AI 生成内容」。
