# 上线运营手册

## 一、定价建议

| 档位 | 说明 | 建议售价 |
| --- | --- | --- |
| mock 免费 | 全流程试跑（占位画面 + 真实剧情/字幕/小说） | ¥0 |
| 单集 | fast 档 1 集（约 2 分钟） | ¥2-3 |
| 10 集包 | fast 档，含合集与交付包 | ¥20-25 |
| 整剧 60 集 | fast 档，约 2 小时 | ¥120-150 |

> 实际成本约 ¥50-100/集（视频为主），整剧套餐建议留 30-50% 毛利，并用 mock 档引流。

## 二、用户教程（写给小白）

1. 注册后系统赠送 ¥10 体验金。
2. 首页选模板或输入一句话 → 选「mock 免费试跑」→ 点开始。
3. 在项目页实时看进度，完成后下载交付包（成片+小说+剧本+图+投稿规范）。
4. 满意后充值真实档，生成可投稿成片；投稿前在平台勾选 AI 标识。

## 三、常见故障排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 一直停留在某阶段 | 网络或上游 API 慢 | 等待或点"继续生成"（断点续跑） |
| 某集失败 | 上游返回异常 | 查看失败步骤，点"继续生成"自动重试失败集 |
| 余额被扣但没生成 | 冻结后失败 | 实际消耗计费，未消耗部分自动退款 |
| 视频卡在"视频生成" | Seedance 队列长 | 等待；资源包不足时前端会预警 |
| 图片/视频都是色块 | mock 档占位 | 正常现象；配置密钥后生成真实内容 |

## 四、内容合规红线

- 勾选 AI 生成标识（代码已默认在片头画面与元数据中标注）。
- 拒绝生成：色情、暴力血腥特写、赌博、毒品、邪教、侮辱国家、侵犯他人名誉权/肖像权。
- 投稿前自查，平台有审核前置拦截，违规会封号。

## 五、上线检查清单

- [ ] 域名 + HTTPS（见 `scripts/deploy/README.md`）
- [ ] `.env` 配置真实密钥与 `CORS_ORIGINS`、`SECRET_KEY`
- [ ] 火山资源包余额充足 + `VOLC_ACCESS_KEY/VOLC_SECRET_KEY` 已配置
- [ ] 用 1 集真实档端到端验收（生成→下载→试播）
- [ ] 注册/登录/充值流程可用（支付接入商户号）
- [ ] 备案完成（国内服务器）
