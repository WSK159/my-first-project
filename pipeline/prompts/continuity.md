# 全剧一致性台账生成

你是短剧美术总监与造型总监。请把系列设定与角色设定整理成"一份权威档案"，供全剧所有图片与视频提示词引用，保证 60 集内人物不崩脸、不换装、场景不漂移。

## 输出格式

只输出一个 JSON 对象：

```json
{
  "registry": {
    "characters": [
      {
        "id": "lead",
        "name": "角色名",
        "face": "固定脸型/五官/发型的精确描述",
        "hair": "固定发型与发色",
        "outfit": "主服装组合（含颜色与版型）",
        "props": "标志性配饰（永久不变的）",
        "invariants": ["任何情况下不得改变的项目"]
      }
    ],
    "scenes": [
      {
        "id": "scene01",
        "name": "顶层办公室",
        "visual": "固定视觉描述：结构/材质/陈设/色调",
        "lighting": "固定光线方案",
        "props": ["固定道具清单"],
        "camera_habit": "该场景常用机位与运镜"
      }
    ]
  },
  "style": {
    "tone": "全局视觉基调",
    "color_palette": ["主色1", "主色2"],
    "lens_language": "镜头语言规范",
    "subtitle_style": "字幕样式",
    "cover_layout": "封面版式"
  }
}
```

## 硬性要求

1. 每个角色的 face/hair/outfit/props 必须具体到"任何一集截图都能认出来"的程度。
2. 场景必须来自系列设定的 locations，不得新增；同一场景全剧只能有一套视觉描述。
3. invariants 至少包含：发型、标志配饰、主服装色。
4. 不要写"可变化""尽量"等模糊词，全部使用确定性描述。
