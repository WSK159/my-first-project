# 音频导演提示词模板（Seed Audio）

输入：最终成片时间轴（EDL 锁定后重建的 `final_storyboard_for_audio.json`）。

按"音频导演 cue sheet"顺序改写为一段提示词（每段 ≤120 秒、≤2048 字符）：

```text
1. 持续环境：房间底噪 / 人群 / 车流 / 天气 / 机械 / 电话线路底噪
2. 音乐 bed：主奏乐器、辅奏、情绪、强度，以及对白下方是否减弱
3. 时间线 cue：按顺序的开场效果与动作音
4. 角色标签：角色名、年龄、性别、口音、音色、情绪表演
5. 精确对白：用引号写出要说的台词
6. 穿插效果：放在台词之间，标注时机
7. 结尾约束：收尾音、淡出、"人声靠前""不要有噪声盖住台词"等
```

示例：

```text
背景持续有雨声和远处车流，音乐以极弱的钢琴铺底，情绪克制而压抑。
先是一声门被推开。林晚（青年女性，普通话，清冷克制）低声说："你来晚了。"
随后远处传来一声闷响，她停顿半拍又说："外面……是什么声音？"
最后一声电流杂音，画面切黑。人声清楚靠前，不要让噪声盖住台词。
```

约束：

- 对白用严格 TTS（`只朗读：...读完立即停止`）或独立分轨。
- 长音频按自然断点分段，并行生成后 FFmpeg 拼接。
- 不要从分片级音频直接拼接全片；先锁 EDL，再重建全片音频时间轴。
