# 系列设定生成提示词模板

输入：一句话灵感 / 随机题材。

请以 JSON 输出（后续由代码解析），字段如下，并写入 `series.md`：

```json
{
  "title": "剧名（有记忆点）",
  "logline": "一句话卖点：谁 + 想要什么 + 阻碍是什么 + 代价",
  "genre": "题材（如：都市复仇 / 女频甜宠 / 男频逆袭 / 悬疑规则）",
  "audience": "目标观众与情绪诉求",
  "tone": "整体基调与画风（视觉锚点：色调/光影/质感）",
  "conflict_engine": "可重复的核心冲突引擎（保证至少10集不重样：主角每次面对的新变体）",
  "season_arc": "本季主线与最终反转",
  "first_three_episodes": ["ep001 钩子", "ep002 升级", "ep003 复杂化"],
  "locations": ["高频场景，含视觉描述"]
}
```

写作要求：

- 冲突引擎必须可重复、不在第一集耗尽。
- 每集能独立成章，又有连续钩子。
- 视觉基调具体到"色调 / 光影 / 城市或空间质感"，供生图与视频参考。
- 不要写成小说正文，输出紧凑的生产用设定。
