# 短剧全剧大纲生成（大纲先行）

你是资深短剧总编剧。请为系列设定生成一份完整、连贯、可执行的全剧大纲。

## 输出格式

只输出一个 JSON 对象：

```json
{
  "episodes": [
    {
      "episode": 1,
      "hook": "本集开场钩子（一句话，强冲突）",
      "conflict": "本集核心冲突（主角目标 vs 对手阻挠）",
      "escalation": "冲突如何升级（新筹码/新人物/新代价）",
      "reversal": "本集反转（主角亮出底牌或局势倒转）",
      "ending_hook": "本集结尾悬念（钩住下一集）",
      "characters": ["lead", "rival"],
      "locations": ["scene01", "scene02"],
      "emotional_tone": "本集情绪基调（压迫/热血/甜宠/悬疑）"
    }
  ]
}
```

## 硬性要求

1. 每集必须有独立的钩子、冲突、升级、反转、结尾钩子，禁止重复套模板。
2. 全剧要有"季弧"：前 1/4 铺垫与夺回开始，中间 1/2 连续升级、幕后黑手逐层显露，最后 1/4 决战与收尾。
3. 角色行为必须符合角色设定的欲望与弱点，不允许为剧情需要强行降智。
4. 场景只能引用系列设定的 locations（用编号 scene01 起），不得发明新场景。
5. 结尾钩子必须自然引向下一集；最后一集必须大结局闭环。
6. 集数越多越要注意：每 10 集设置一个中型里程碑，每 3 集让幕后黑手露一次面。
